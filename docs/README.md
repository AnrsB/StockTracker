# StockTracker - Personal Stock Portfolio Manager

A modern, free stock tracking application that helps users monitor, manage, and analyze their investment portfolio.

## Project Overview

StockTracker is a web-based application designed to help individual investors track their stock holdings, monitor watchlists, and analyze their portfolio performance in real-time using free market data APIs.

## Key Features

- **Search Page**: Browse and search stocks by name or ticker symbol with real-time data
- **Price History**: View historical price charts (24h, 1 week, 1 month, 1 year, all-time)
- **Watchlist**: Monitor stocks of interest without owning them
- **My Wallet**: Track your actual stock holdings with buy/sell history
- **Portfolio Analytics**: See overall gains/losses and performance metrics

## Tech Stack

- **Frontend**: Vanilla HTML, CSS, JavaScript with jQuery
- **Database**: Firebase Realtime Database
- **API**: Finnhub (stock market data)
- **Authentication**: Firebase Authentication
- **Hosting**: Firebase Hosting (optional) or Vercel/Netlify
